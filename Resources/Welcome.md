# Typora Native

在 macOS 上，直接写 Markdown。

## 专注于内容

这是 **加粗**、*斜体*、~~删除线~~ 和 `行内代码`。点击这一段即可编辑原始语法，移开光标后恢复排版。

> 原始文本是唯一内容来源。预览只改变显示，保存不会整理未修改段落。

## 原生编辑

- 使用 ⌘B / ⌘I 设置格式
- 使用 ⌘⇧M 切换源码与实时预览
- 使用 ⌘F 查找，⌥⌘F 替换
- 点击左侧大纲跳转章节

### 表格

将光标放进表格，点击工具栏的表格按钮，即可在原生网格中编辑。Tab 切换单元格。

| 能力 | 状态 | 说明 |
| :--- | :---: | --- |
| 原生窗口 | 支持 | AppKit |
| 原文保持 | 支持 | 按范围修改 |
| 导出 | 支持 | HTML / PDF |

### 代码

```swift
let message = "Hello, macOS"
print(message)
```

在代码块内点击工具栏代码按钮，可以修改语言。

## 文件与分享

拖入图片会复制到文档旁的 assets 文件夹。保存前会检查文件是否已被其他应用修改，未保存内容会写入本地恢复草稿。

[访问 Markdown 语法说明](https://support.typora.io/Markdown-Reference/)
